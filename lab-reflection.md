# My Cybersecurity Lab Reflection

## Introduction
In this lab, I practised using Git and GitHub for managing a cybersecurity project. I learned how to create repositories, upload files, and keep track of changes.

## What I Learned
I learned how to use Git commands such as init, add, commit, push, pull, and clone. I also learned how to create a README file and use a .gitignore file to avoid uploading unwanted files.

## Challenges I Faced
One of the main challenges was resolving a merge conflict in my README file. At first, I was confused by the conflict markers, but I learned how to edit the file, remove the markers, and complete the merge.

## Skills I Developed
This lab gave me more practice with the Linux terminal, Git commands, GitHub repositories, and version control. I also became more familiar with organizing project files.

## Conclusion
Overall, this lab was a useful learning experience. It helped me understand how Git and GitHub work together and gave me more confidence in managing my own project.
