 Cyber Security Lab Portfolio

 About This Repository

This repository contains my cybersecurity lab activities, practical exercises, and learning progress. I created it to organize my work and keep a record of the skills I develop during my cybersecurity course.

 Course Information

Course: Cybersecurity Lab  
Institution: Air University, Islamabad  
Purpose: To gain practical experience with cybersecurity concepts, Linux commands, Git, and GitHub.

 My Lab Work

In this repository, I have documented my practical learning activities, including:

- Basic Linux commands and terminal practice.
- Git and GitHub commands and version control.
- Repository creation, cloning, pulling, and pushing.
- Working with branches and resolving merge conflicts.
- Basic cybersecurity practices and protecting sensitive information.

 Files Included

- README.md: Provides an introduction to this repository and its contents.
- git-commands-notes.txt: Contains notes about Git commands I learned and practised.
- lab-reflection.md: Describes my learning experience and the practical skills I developed.
- .gitignore: Specifies files that should not be tracked by Git.

Learning Goals
My goal is to improve my practical cybersecurity skills, become more confident with Linux and Git, and continue learning about information security. I also want to build a collection of practical projects that demonstrates my progress.
